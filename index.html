API 키를 넣으면 위 규칙대로 바로 채점하다가, 오답(부분 정답 포함)이 나왔을 때만 AI가 뜻을 이해해서 다시 확인해요. 단어장과 표현이 달라도 같은 뜻이면 정답으로 바뀌어요. 인터넷이 안 되면 규칙 채점 결과 그대로예요.

API 키를 넣으면 직접 입력에서 틀렸을 때(확인을 누르거나 1.2초 멈추면) AI가 두 예문을 보고 왜 안 맞는지 말풍선으로 알려줘요. 정답은 말하지 않아요. 철자 한두 글자 실수는 AI 없이 바로 알려줘요. 인터넷이 안 되면 기본 말풍선 그대로예요.

  1. Groq API 키 만들기 페이지 열기 (이메일·구글·GitHub로 가입, 무료, 카드 필요 없음). Create API Key 누르기
  2. 만든 키(gsk_…)를 복사해서 아래에 붙여넣고 연결

무료라서 하루에 쓸 수 있는 횟수가 정해져 있어요. 한도를 넘으면 그날은 규칙 채점만 해요. Groq가 안 되면 OpenRouter 키(sk-or-…, GitHub로 가입, 무료 모델은 하루 50번쯤)도 돼요. Gemini(AIza…)·Claude(sk-ant-…, 유료) 키도 넣을 수 있어요.

키는 이 기기에만 저장돼요. 비밀번호처럼 다른 사람에게 보내지 마세요.

폰·아이패드 진도 자동 동기화

GitHub 토큰을 기기마다 한 번씩 넣어두면 진도가 자동으로 합쳐져요. 예문·단어 모드 진도가 함께 내 GitHub 계정의 비밀 Gist에 저장돼요.

  1. 토큰 만들기 페이지 열기 (GitHub 로그인 필요)
  2. Expiration을 No expiration으로 바꾸고 맨 아래 Generate token 누르기 (gist는 이미 체크돼 있어요)
  3. 나온 토큰(ghp_…)을 복사해서 아래에 붙여넣고 연결
  4. 다른 기기에서도 같은 토큰을 붙여넣기 (연결된 기기의 "토큰 복사" 버튼 사용)
