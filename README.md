# VOCA 빈칸 암기

폰 브라우저에서 쓰는 영단어 암기 웹앱입니다. 두 예문에 뚫린 빈칸에 **공통으로 들어갈 말**을 맞혀요.

## 데이터

저장소 루트에 있는 CSV 파일을 읽습니다(UTF-8 / UTF-8-BOM 모두 가능).

- `VOCA_26-37.csv`
- `VOCA_38-50.csv` ← 새 DAY는 이 파일에 행만 추가해서 같은 이름으로 올리면 앱에 바로 반영돼요.

파일 이름을 바꾸거나 새 파일을 추가하려면 `js/files.js`의 `DATA_FILES`를 고치면 됩니다. (예문·단어 모드가 같이 씀)

컬럼은 머리글 이름으로 자동 인식해요. 순서는 상관없어요.

| 용도 | 인식하는 머리글 예시 |
|---|---|
| DAY | `DAY`, `Day`, `일차` (값은 `26`, `DAY 26` 모두 가능, 비어 있으면 위 행의 DAY를 이어받음) |
| 단어 | `단어`, `영단어`, `표현`, `word` |
| 뜻 | `뜻`, `의미`, `meaning` |
| 예문 / 예문2 | `예문`, `예문2` |
| 예문 해석 | `예문해석`, `예문2해석`, `해석`, `해석2` (해석의 뜻 부분은 굵게 강조) |
| 빈칸 정답 (선택) | `빈칸형태` — 없으면 `단어`로 예문에서 자동으로 찾음 |
| 해석강조 (선택) | 해석에서 강조할 말. 뜻과 해석이 다른 말이라 자동으로 못 찾을 때 씀 (`highlights.json`에 단어별로 적어도 됨) |
| 형광 (선택) | 있어도 되지만 앱에는 표시하지 않음 |
| (선택) | `품사`, `발음기호` — `유의어`·`반의어`·`파생어`·`표현숙어` 등 그 밖의 컬럼은 정답 화면에 그대로 표시 |

### 빈칸 만드는 방식

숙어는 단어마다 칸이 하나씩 뚫려요(cutting off → [cutting] [off]). 직접 입력에서 한 칸을 다 채우면 다음 칸으로 넘어가요.

`빈칸형태`가 없으면 `단어` 컬럼으로 예문에서 찾아요. 변화형(convinced, studied, stopped, cutting), 불규칙 동사(flung, strode, took over), 떨어진 구동사(let his son down → [let] his son [down])도 찾아요.
`빈칸형태`를 쓸 땐 예문에 실제로 들어 있는 형태로 적고, 사이에 다른 말이 끼는 숙어는 `~`, `…`, `...`, `A`, `B`, `sb`, `sth`, `one's` 등으로 구분하면 됩니다.

- `convinced ~ of` → *She **[convinced]** the jury **[of]** his innocence.*
- `convince A of B`처럼 원형으로 적어도 예문의 `convinced`를 찾아서 빈칸으로 만들어요.
- `make up one's mind` → *She **[made up]** her **[mind]**.*

## 기능

- 화면 아래 탭(아이콘만): 진도(DAY별 진도) · 단어장 · **홈**(가운데) · 코치 · 설정. 코치를 끄면 코치 탭, 고급 기능을 끄면 설정 탭이 빠지고 홈이 가운데로 다시 놓임 (`js/app.js`의 `renderTabs`). 퀴즈·학습 계획·결과 화면엔 탭이 없음. 폰 키보드가 올라오면(코치 채팅) 탭을 숨김. 넓은 화면(1000px~, 컴퓨터·가로 아이패드)에선 아래 탭 대신 왼쪽 세로 메뉴(아이콘 + 작은 이름, 홈이 맨 위)이고, 홈은 두 칸(왼쪽 크게 '오늘' 카드, 오른쪽 학습 계획·암기 완료·다시 볼 단어). 세로 아이패드는 폰처럼 아래 탭
- 디자인: 옅은 회색 바탕에 흰 카드, 테두리·그림자 없이 색 차이로만 나눔. 카드 하나에 정보 하나, 숫자는 크고 굵게·설명은 작고 흐리게. 화면마다 진한(인디고) 버튼은 하나. 작은 도구 버튼(힌트·모르겠어요·보내기·기억·지우기 등)은 아이콘만(이름은 `aria-label`·`title`)
- 홈은 오늘 할 일만: '오늘' 카드(시작할 게 있으면 인디고로 칠해지고 카드 어디를 눌러도 시작. 숫자 옆 ✎·학습/복습/더 하기 이동은 따로 눌림. 오늘 몫을 다 했거나 '더 하기'면 흰 카드) → '학습 계획' 요약 카드(범위를 크게 + 문제 방식·하루 개수 한 줄) → 암기 완료 카드(외운 수 / 범위 단어 수 + 막대. 배운 수는 학습 계획 화면의 학습 범위 카드에) → 다시 볼 단어·범위 순서대로 연습 목록. 헤더는 앱 이름과 조용한 모드 전환(동기화 상태는 작은 점 하나, 글자는 title). 요약 카드를 누르면 **학습 계획** 화면(설정과 같은 '이름 ─ 값' 줄)에서 학습 범위·문제 방식·예문 해석·단어 코치·하루 새 단어 수·목표일(시험일 바로 위, 설정 > 복습의 목표일과 같은 칸. 코치가 켜져 있으면 코치 일정의 목표일)·시험일(옆에 D-n)을 바꿈. 하루 복습 수는 없음(복습일이 된 단어 전부, 오늘 몫은 '오늘' 카드 숫자를 눌러 바꿈). 설정 > 화면 > '홈 간단히 보기'를 끄면 예전처럼 홈에 모두 보임 (기기마다 저장, 예문·단어 모드 같이)
- DAY 범위 선택(시작~끝, 최신 DAY, 최근 3 DAY, 전체)
- 4지선다 / 직접 입력(앱 자체 영어 키보드 — 키 사이 틈이나 가장자리를 눌러도 가장 가까운 키가 눌림, 설정에서 폰 키보드로 변경 가능), 힌트(4지선다: 틀린 보기 두 개를 지움 · 직접 입력 1번: 맞게 쓴 데까지 + 2글자, 2번: 정답을 회색으로 보여주고 따라 쓰기 — 틀린 것으로 기록). 힌트를 쓴 채 그만둬도 그 문제는 힌트 쓴 걸로 남음. 4지선다 보기는 정답과 낱말 수가 같고(숙어 문제에 한 단어 보기가 섞이지 않게) 예문에서 쓰인 품사가 같은 것부터 고름(형용사 자리에 동사 보기가 나와 문장 구조만으로 답이 보이지 않게. 품사는 CSV의 `품사`, 없으면 한국어 뜻으로 짐작). 틀렸거나 힌트를 썼으면 정답 시트에 '보기 풀이'(보기마다 무슨 단어·뜻인지, 내가 고른 보기 표시). 두 예문의 빈칸 형태가 다르면(deteriorated / deteriorate) '공통으로' 대신 "빈칸에 들어갈 단어는?"으로 물음. 예문 한 칸에 문장이 여럿이면(` / `로 이어 적음) 문장마다 줄을 나누고 해석을 바로 아래에 폰·태블릿 4지선다는 보기를 2×2로 예문 바로 아래에 두고, 한 화면에 다 안 들어갈 때만 화면 아래에 고정(아이패드 세로처럼 큰 화면은 보통 예문 바로 아래). 고정될 땐 힌트 버튼을 고정된 칸 위쪽 줄(쏠림 ‹ › 옆)로 옮겨 예문 글자를 가리지 않고, 마지막 예문 글자가 가려져 있으면 그 줄 오른쪽에 '더 보기'(누르면 내려 줌, 끝까지 보이면 숨음). 아주 작은 폰(높이 640px 이하)은 예문 칸을 촘촘하게
- 복습은 외운 단어만 4지선다 (학습 계획 화면의 문제 방식 아래 스위치, 처음엔 꺼짐, 기기끼리 맞춰짐): 켜면 오늘의 복습 · 추가 복습(과 거기서 틀린 단어 다시 풀기)에서만 위 문제 방식 대신 단어마다 정함. **직접 입력을 한 번에(힌트 없이, 처음 나왔을 때) 맞힌 단어는 다음 복습부터 4지선다**로 뜻만 떠올리고, 직접 입력에서 틀렸거나 힌트를 쓴 단어 · 4지선다에서 틀렸거나 힌트를 쓴 단어는 한 번에 맞힐 때까지 직접 입력(단어마다 `q`, 배울 때 직접 입력으로 한 번에 맞히면 첫 복습부터 4지선다, 4지선다로 배웠으면 첫 복습은 직접 입력). 맞히면 졸업하는 문제는 4지선다 차례여도 직접 입력(찍어서 졸업하지 않게). 이번 학습에서 틀렸거나 힌트를 쓰고 다시 나온 단어도 직접 입력. 20개 묶음 안에서 4지선다로 나올 단어를 먼저, 직접 입력을 나중에 냄(키보드가 한 번만 올라오게). `q`가 없는 예전 기록은 예전 규칙(3단계 이상이면 4지선다). 새 단어 학습·다시 볼 단어·범위 연습 등은 위 문제 방식 그대로 (`js/core.js`의 `questionKind`·`choicesFirst`)
- 간격 반복: 단어마다 단계(0~4)와 다음 복습일 저장
  - 힌트 없이 맞히면 단계 +1 → 1일 / 3일 / 7일 / 14일 뒤 복습. 14일 단계(암기 완료)에서 또 맞히면 간격이 두 배씩(28 → 56 → 112 → 120일, `MASTER_GROW`·`MAX_INTERVAL`)
  - **졸업**: 암기 완료 뒤 간격이 단어책 28일(`GRAD_BOOK`) · 내 단어와 독해에서 막힌 단어책 단어 56일(`GRAD_MY`) 이상인 복습을 힌트 없이 맞히면 졸업(`g` = 졸업한 날). 졸업한 단어는 복습에 안 나오고(시험 전 범위 전체 훑기에는 나옴) 단어장 '졸업'에 모임. 졸업 없이 120일 간격으로 계속 돌면 배운 단어가 늘수록 복습이 끝없이 늘어서. 졸업한 단어를 연습·훑기에서 틀리거나 힌트를 쓰면 졸업이 풀리고 다시 복습 (`applyResult`·`willGraduate`)
  - 힌트 쓰고 맞히면 단계 그대로 내일 다시, 틀리면(정답 보고 쓰기 포함) 0단계(다시 볼 단어)로 내일 다시. 다시 맞히면 처음부터가 아니라 틀리기 전 단계보다 두 단계 아래에서 이어 감(14일 단계에서 틀렸으면 다음엔 7일 뒤). 0단계에서 또 틀리면 더 내려감 (`js/core.js`의 `LAPSE_DROP`)
  - 복습일이 지나서(밀려서) 맞히면 그동안 기억한 날 수보다 짧은 간격은 건너뜀 (1단계 단어를 열흘 만에 맞히면 3·7일을 건너 14일 뒤)
  - 다음 복습일은 정해진 간격 앞뒤 15%쯤(4일 넘는 간격만: 7일 → ±1일, 14일 → ±2일) 안에서 복습이 덜 잡힌 날로, 쉬는 요일은 피해서 고름. 같은 날 배운 단어가 한날에 몰려 돌아오지 않게
  - 같은 학습 안에서 다시 나오기 (설정 > 문제 풀기 > '다시 나오기', 두 모드 같이·기기끼리 동기화): 틀렸을 때 · 힌트 두 번(정답 보고 따라 쓰기) · 힌트 한 번(힌트 쓰고 맞힘, 부분 정답)마다 다시 나올 때를 여러 개 고름 — 곧(1~2문제 뒤) · 조금 뒤(3~5) · 나중에(8~12) · 맨 끝(이번 학습 마지막). 고른 때마다 한 번씩 나오고, 하나도 안 고르면 이번엔 안 나옴. 남은 문제가 모자라면 맨 끝으로. 다시 나왔을 때 또 틀리거나 힌트를 쓰면 남아 있던 건 지우고 새로 잡음. 다시 나온 문제는 연습이라 맞혀도 복습 단계는 첫 결과대로(내일 다시). 맞혔는데 이번 학습에 또 잡혀 있으면 채점 표시에 '내일 다시' 대신 언제쯤 또 나오는지를 숫자 없이 느낌으로(얼마나 뒤인지에 따라 '곧·금방', '잠시 후·좀 있다가', '한참 뒤에·나중에', '끝날 때쯤·마지막에' 등에서 그때그때 하나. 예: '정답! · 잠시 후 한 번 더'), 마지막으로 나온 때만 '내일 다시'. 고르는 칸은 상황(줄) × 때(칸) 표. 위의 세 단계로 한 번에 맞출 수 있음: 가볍게(틀렸을 때·힌트 두 번만 조금 뒤, 이 설정이 생기기 전과 같음) · 추천(기본: 틀리면 조금 뒤·맨 끝, 힌트 두 번은 조금 뒤·나중에, 힌트 한 번은 나중에) · 꼼꼼하게(틀리면 곧·나중에·맨 끝, 힌트 두 번은 조금 뒤·나중에·맨 끝, 힌트 한 번은 조금 뒤·맨 끝). 유반의어 테스트는 '틀렸을 때'·'힌트 한 번'을 따름
  - 하루는 새벽 4시에 바뀜: 그때 새 '오늘의 학습'·복습이 나오고, 0시~3시 59분에 공부한 건 전날 몫으로 침 (`js/core.js`의 `DAY_START_HOUR`)
  - 오늘의 학습 = (시험 3일 전부터) 범위 단어 3등분 중 오늘 몫 → 새 단어(하루 개수만큼, 학습 범위에서 순서대로)
  - 홈의 '오늘' 카드 하나가 학습 → 복습 → 더 하기 순서로 바뀜
  - 오늘의 복습·추가 복습은 학습 범위 안의 단어에서만 고름
  - 오늘의 복습 (오늘의 학습을 끝내면 나옴) = 복습일이 된 단어 전부, 개수 제한 없음(까먹었을 가능성이 큰 것부터: 지난번에 본 뒤 지난 날 ÷ 원래 간격이 큰 순, 간격 1일짜리가 사흘 밀린 게 14일짜리가 사흘 밀린 것보다 먼저). '복습' 숫자를 누르면 오늘만 줄이거나 늘림. 오늘 배운 단어·오늘 이미 본 단어는 빼고, 시작할 때 그날 목록이 정해짐. 풀 때는 그 순서대로 20개씩 묶어 묶음 안에서만 섞어서, 밀린 게 많아 중간에 그만둬도 급한 것부터 한 셈
  - 복습이 평소보다 많이 밀리면(30개 넘고, 앞으로 7일 동안 하루에 돌아올 양(적어도 10)의 두 배 넘게) '오늘의 복습' 아래에 왜 쌓이는지를 숫자로: 새 단어 1개는 하루 복습 5개쯤으로 돌아옴(`REVIEW_PER_NEW`) → 지금 하루 새 단어 수면 복습이 하루 몇 개까지 느는지 (`reviewPace`)
  - 더 하기 (오늘의 복습까지 끝내면 나옴): 개수(5/10/20/40 버튼 또는 슬라이더로 5개 단위 5~100개)를 골라 추가 학습(범위의 다음 새 단어) / 추가 복습(오늘의 복습과 같은 방식으로 다음 단어들, 다 떨어지면 오늘 본·배운 단어도 약한 것부터 다시)
  - 학습이 끝나면 점수 대신 틀렸거나 헷갈린 단어 목록을 보여 주고, 그 단어만 다시 풀 수 있음
  - 시험일을 정하면: 다음 복습일이 시험 뒤인데 시험날까지 간격의 절반보다 많이 남으면 시험 전에 한 번 더(시험까지 간격의 절반이 남는 날, 14일 간격이면 시험 7일 전). 간격마다 날이 달라 한날에 몰리지 않고 약한 단어일수록 시험에 가깝게 봄 (`EXAM_FRAC`). 예전처럼 모든 복습일을 시험 전날로 당기지는 않음
  - 복습일이 아닌 단어를 연습으로 맞힌 건 일정에 반영하지 않음 (틀리면 반영)
- 단어 코치 (설정 > 복습 방식 또는 학습 계획 화면의 '단어 코치' 스위치. 처음엔 꺼져 있고 홈에서 한 번 켤지 물어봄. 예문·단어 모드가 같이 켜지고 꺼짐)
  - 시험일만 정하면 남은 날을 '새 단어를 배우는 날'과 '범위 전체를 다시 훑는 날'로 나눠 목표일과 하루 새 단어 수를 정함. 새 단어 하나는 문제 네 번쯤의 품(`NEW_COST`), 총정리는 단어마다 단어·예문 두 문제(`SWEEP_COST`)로 보고 두 기간의 하루 부담이 비슷해지게 나눔 (처음부터면 남은 날의 1/3쯤이 총정리: 2주 남았으면 9일 배우고 5일 총정리. 이미 많이 배웠으면 총정리 날이 늘어남. 일정을 새로 짤 때만 적용돼서 이미 짠 목표일은 그대로). 훑는 날은 적어도 하루(엿새 넘게 남았으면 이틀)는 남기고, 하루 10개도 안 되게 늘어지면 10개씩 당겨 끝냄
  - 오늘 새 단어 수 = 남은 새 단어 ÷ 목표일까지 남은 날 (매일 다시 계산. 밀리면 늘고 앞서가면 줄어듦). 복습은 아래 '복습 주기·목표일' 그대로
  - 일정을 다시 짜는 때: 시험일·학습 범위를 바꿨을 때, '일정 다시 짜기'를 눌렀을 때, 목표일이 됐는데 새 단어가 남았을 때(자동). 새 단어를 일찍 다 끝내면 다음 날부터 바로 전체 훑기
  - 코치 캐릭터는 고양이·햄스터·부엉이·슬라임 넷 중에서 고름(32×32 픽셀 그림, `js/coach-art.js`). 캐릭터마다 이야기·역할·말투가 있음(`js/ai.js` `COACH_PERSONA`): 고양이 = 헌책방에서 영어 소설을 몰래 읽으며 자란 까칠한 과외 선배(짧고 담백, 칭찬은 돌려 말함), 햄스터 = 단어를 씨앗처럼 모으는 응원단장(들뜸, 씨앗·저금통 비유), 부엉이 = 도서관 꼭대기의 사서 선생님(차분, 까닭과 어원), 슬라임 = 연못가의 말랑한 쉼터 친구(느긋, 다독임). 고르는 창에 한 줄 소개가 나옴. 코치를 처음 켤 때 고르는 창이 뜨고(취소하면 안 켜짐), 설정 > 복습 방식의 '코치 캐릭터'에서 언제든 바꿈. 고른 캐릭터는 그 기기에 저장되고 두 모드가 같이 씀. 동기화(아래 GitHub 토큰)를 켠 기기끼리만 더 최근에 고른 캐릭터로 맞춰짐(Gist의 `voca-marks.json`. 이 기능 전에 고른 거라 언제 골랐는지 모르면 먼저 동기화한 기기의 캐릭터를 따름). 동기화를 안 켰으면 다른 기기와 아무것도 주고받지 않음
  - 아래 '코치' 탭에서 고른 캐릭터가 메신저처럼 알려 줌(AI가 꺼져 있으면 오늘 할 말 한 줄과 할 일 버튼, 켜져 있으면 아래 '코치와 이야기하기' 채팅이 그대로 이 탭): 시험까지 며칠, 언제까지 새 단어, 오늘 몫 / 밀렸을 때(처음 계획의 1.25배 넘게) '일정 다시 짜기' / 하루 80개 넘게 벅차면 범위 줄이기 권유 / 오늘 몫 끝 / 시험 날 / 시험 끝. 표정 다섯 가지(기본·정답·오답·응원·졸림)를 상황에 맞게 씀. 문제를 풀 때 정답 시트 한쪽에서 맞으면 기뻐하고 틀리면 울상, 학습이 끝난 화면에도 나옴
  - 쉬는 요일 (설정 > 복습 방식의 요일 버튼, 또는 코치에게 말로): 그날은 새 단어·총정리 몫 없이 쉬고(복습일 된 단어만), 하루 개수는 공부하는 날로만 나눔. 일주일 내내 쉴 수는 없음. 예문·단어 모드가 같이 씀(한쪽에서 바꾸면 다른 쪽도, 시험일처럼 더 최근에 바꾼 쪽으로 기기끼리 동기화)
  - 코치와 이야기하기 (AI가 켜져 있을 때 코치 탭·설정의 버튼): 메신저처럼 주고받는 대화 화면(코치 탭 안, 다른 탭으로 가도 받는 중인 말은 마저 받아 저장). 주제·길이·횟수 제한 없이 무엇이든 말하면 AI가 코치로서 답함(단어 뜻·어원, 외우는 요령, 일정, 고민, 잡담). 코치는 자기 의견이 있어서 계획이 무리면 솔직하게 말함. 코치는 예문·단어 모드가 하나: 이야기와 기억을 두 모드가 같이 쓰고(예전에 모드마다 따로 쌓인 이야기는 처음 열 때 시각 순으로 합침), 지금 보는 모드의 진도·일정에 더해 다른 모드의 진도(범위, 배운·새 단어, 다시 볼 단어, 암기 완료, 오늘 배운 수, 마지막 공부한 날, 일정)도 앎. 약한 단어(많이 틀린 단어 — 두 모드 기록을 합쳐 어느 모드에서 몇 번 틀렸는지까지, 복습일이 지난 단어)를 알고 있어서 먼저 짚어 주고, 퀴즈를 내 달라고 하면 그 단어로 냄. 이야기와 코치가 기억해 둔 학생 사정(예: 수요일은 학원)은 날이 바뀌어도 이어지고, 동기화를 켜면 기기끼리도 맞춤(Gist의 voca-coach.json. 지운 기억·'모두 지우기'는 다른 기기에서 되살아나지 않고, 그날 첫 인사는 하루에 하나만). 코치는 실제 학습 기록도 앎: 문제를 풀 때마다·학습을 시작하고 끝내거나 그만둘 때·정답 화면에서 AI에게 물을 때 한 줄씩 남기고(두 모드 같이, 최근 14일·800줄, 같은 파일로 기기끼리 맞춤), 말할 때마다 최근 학습을 학습 하나씩(언제·무엇을·몇 문제, 끝냄·그만둠·푸는 중, 틀린 단어와 그때 고르거나 쓴 답, 힌트 쓴 단어, 가장 최근 학습에서 푼 순서, AI에게 물어본 것) 정리해 넘김. 그래서 '방금 뭐 틀렸어?', '아까 그 단어 뭐였지?'에 답하고, 지난번 말 뒤에 새로 한 학습은 학생이 말하지 않아도 알아봐 줌. 동기화를 켰으면 코치에게 말을 보내기 전에 한 번 받아 와서(4초까지만 기다림) 다른 기기에서 방금 한 학습·이야기까지 알고 답함. '기억' 버튼에서 보고 지울 수 있음. 일정 얘기면 AI는 학생이 원하는 값(쉬는 요일 · 하루 새 단어 수 · 시험 전 총정리 날 수 · 오늘 새 단어 수)만 뽑고 AI는 한 번만 부름. 계산과 숫자는 앱이 말풍선 아래 카드로 보여 줌(예: '토요일 빼고 하루 40개씩 하면 복습이 며칠?' → 하루 40개 그대로 계산. 남는 단어가 있으면 [마지막 날에 붙이기] [하루 늘리기] 가운데 고름. 그 개수로 모자라면 적어도 몇 개인지 알려 줌). 카드의 '이렇게 할게요'를 눌러야 바뀜. 하루 개수·복습 날 수는 지금 보는 모드 일정만 바뀌고(카드 제목에 모드 이름), 쉬는 요일은 두 모드가 같이 바뀜. 하루 개수를 정하면 그 개수로 고정되고(동기화됨) 복습 날 수는 진도를 따라 정해짐. 고른 모델이 막히면(사람이 몰림 503, 한도 429, 너무 늦음 — 대화는 긴 설명을 쓰는 중일 수 있어서 30초까지 기다림) 다른 모델로 넘어가고(Gemini는 flash → flash-lite), 그래도 안 되면 까닭을 말하고 '다시 보내기'를 보여 줌. 토큰 아끼기: AI에 넘기는 앞선 이야기는 최근 것만(Gemini·Claude 30개·5000자, Groq 24개·3000자까지) 넘기고, 그보다 오래된 이야기는 버리지 않고 AI가 700자 안의 '지난 이야기 요약'으로 줄여 같이 넘김(약속, 고민, 퀴즈에서 헷갈린 단어 등을 남기고 인사·잡담·지난 계산 숫자는 버림). 그래서 이야기가 몇 달 쌓여도 한 번에 넘기는 양이 늘지 않음. 줄이기는 창이 넘칠 때만 한 번에(12개·10개만 남기고) 해서 요약은 대략 이야기 일고여덟 번에 한 번, 한 번 더 부름(Claude는 싼 Haiku, 그 밖엔 코치가 쓰는 모델). 요약에 실패하면 10분 동안은 요약 없이 그대로 이야기함. 요약은 '기억' 버튼에서 보고 지울 수 있음. 앞부분은 매번 한 줄씩 밀어 자르지 않고 넘칠 때만 바꿔서 AI 회사의 캐시(같은 앞부분은 싸게 읽음)도 맞음: Claude는 지시문과 앞선 이야기를 캐시해 두고 다음 말에서 1/10 값으로 읽고, Gemini·Groq는 같은 앞부분을 알아서 캐시함
  - 일정 상의하기 (AI가 꺼져 있을 때 코치 탭이나 설정 > 복습 방식의 버튼. AI가 켜져 있으면 대화 화면의 '선택지에서 고르기'): 코치가 시험 전 총정리 날 수를 몇 가지 골라 줌(새 단어 여유 있게 · 코치 추천 · 복습 길게 · 복습 아주 길게, 하루 새 단어가 80개 넘는 건 빼고). 고르면 코치가 그 일정이 어떤지 말해 주고, 정한 날 수는 저장·동기화돼 일정을 다시 짤 때도 따름. 코치 추천을 고르면 다시 코치가 정함. 여기서 고르면 하루 개수 고정은 풀림
  - AI 코치 (설정 > AI를 켜고 키를 넣었을 때, 인터넷이 될 때만): 홈 말풍선을 AI가 고른 캐릭터의 말투로 지음(고양이 시크, 햄스터 들뜸, 부엉이 차분한 선생님, 슬라임 느긋). 학습이 끝나면 결과를 보고 한마디(틀린 단어 하나를 골라 외우는 요령), 일정·개수 계산은 언제나 앱이 하고 AI는 그 사실만 보고 말함. 홈 말풍선과 학습 끝 한마디는 AI가 사실에 없는 숫자를 말하면 버리고 기본 말로. 홈 말은 상황(날짜, 할 일 단계, 일정, 캐릭터)이 바뀔 때만 새로 짓고, 홈 말풍선·학습 끝 한마디처럼 앱이 알아서 AI를 부르는 건 하루 30번까지(무료 한도를 채점에 남겨 두려고. 코치와 이야기하기는 세지 않음). AI가 꺼져 있거나 안 되면 기본 말 그대로. 숨겨 둔 'AI 고급 설정'(설정 맨 아래 '새 버전 확인'을 빠르게 7번 누르면 열림, '고급 설정 숨기기'로 다시 숨김)의 '코치 AI'에 키를 따로 넣으면 코치 말만 그 AI가 짓고 채점은 원래 AI 그대로(예: 채점은 빠른 Groq, 코치는 한국어가 자연스러운 Gemini·Claude). 따로 안 넣으면 코치도 채점용 키를 씀. 설정에 어느 회사에 연결됐는지 보임. 키 연결이 안 되면 까닭을 입력칸 아래에 보여 줌(틀린 키, 그 프로젝트에서 API가 꺼짐, 키 사용 제한, 지역 등, 서버가 보낸 말 포함). 키 앞부분으로 회사를 모르겠으면 Gemini → Groq → OpenRouter → Claude 순으로 물어봄. Google 키는 AIza…와 AQ.… 둘 다 받음(AQ.… 키는 Gemini API가 안 받으면 Vertex AI express로 연결). 코치용 Gemini 키는 flash 모델(채점용은 flash-lite). Claude 키는 채점용·코치용 모두 가벼운 말은 Haiku, 코치와 이야기하기만 Sonnet. 코치용 키를 따로 넣으면 그 한도는 100번. 학습이 끝났는데 다 맞혔으면 짚어 줄 단어가 없어서 AI를 부르지 않고 캐릭터 말투의 칭찬을 앱이 씀
  - 코치를 켜면 '하루 새 단어 수' 버튼은 쓰지 않음(코치가 정함). 목표일 칸에는 코치 일정의 목표일이 나오고, 직접 바꾸면 그날 다음 날부터 시험 전날까지를 총정리 날 수로 정해 일정을 다시 짬(하루 개수 고정은 풀림, 비우면 다시 코치가 정함). 끄면 원래 설정대로. 시험일이 없거나 지났으면 일정 없이 원래 방식으로
- 복습 주기·목표일 (따로 켜는 스위치 없음)
  - 목표일 = 새 단어를 보는 마지막 날. 학습 계획 화면의 시험일 위(설정 > 복습에도 같은 칸)에서 직접 정함. 시험 전전날까지 고를 수 있고, 시험일도 있어야 아래 총정리를 함. 저장은 그다음 날(총정리 시작일)로 `settings.goal`
  - 복습 주기 다섯 가지: 매우 짧게 1·1·2·3·5·8일 / 짧게 1·2·4·7·12일 / 보통(추천, 기본) 1·3·7·14일 / 길게 2·5·12·25일 / 매우 길게 3·8·18·40일. 마지막 단계면 암기 완료, 그 뒤로는 맞힐 때마다 간격이 두 배씩(14 → 28 → 56일 …, 120일까지. 틀리면 원래 간격으로). 마지막 간격으로 끝없이 돌면 배운 단어가 늘수록 복습이 계속 쌓여서. 새로 학습·복습하는 단어부터 적용. 기억 유지 그래프(간단한 망각 곡선 모형)로 비교
  - 목표일 전(목표일이 없을 때도): 오늘의 복습 = 복습일이 된 단어 전부. 복습일을 목표일 전날로 당기지 않음(목표일부터 범위 전체를 훑으니, 예전엔 목표일 전날에 한꺼번에 몰렸음)
  - **총정리** (목표일부터 시험 전날, `js/core.js`의 `pickBothSweep`): 새 단어 없이, 학습 범위 전부를 남은 날에 나눠 하루 몫씩 **예문·단어 두 모드를 한 학습에서 같이** 봄. 예문 모드만 하면 문맥 없이 단어만 봤을 때 바로 읽히는 연습이 빠져서
    - 두 바퀴 (공부하는 날이 4일 이상일 때, `lapOneDays`): **1바퀴**는 앞 70%쯤의 날(10일이면 7일)에 범위 전부를 나눠, 몫의 단어마다 단어 문제(영단어 보고 뜻) + 예문 문제(빈칸) 두 개. **2바퀴**는 남은 날에 약한 단어만 한 번 더, 그것도 약한 쪽 모드 문제만(약한 = 그 모드 단계가 3단계(`WEAK_STAGE`) 아래 — 1바퀴에서 틀리면 0단계라 들어감 — 이거나 그 모드로 안 배움. 날마다 다시 세서 복습으로 단계가 오르면 빠짐). 3일 이하면 1바퀴만. 같은 바퀴에서 그 모드로 이미 본 건 빼고, 빠진 날 몫은 다음 날 같이. 거기에 두 모드 각각 복습일이 된 단어는 그 모드 문제로
    - 예: 10일 · 520단어 → 7일 동안 하루 75단어(150문제)로 한 바퀴, 남은 3일은 약한 단어를 3일에 나눠서 (+ 복습일 된 단어)
    - 훑는 순서는 두 모드 다 잘 아는 단어부터(두 모드 중 약한 쪽 단계가 높은, 두 모드 합쳐 덜 틀린 순, 어느 모드든 안 배운 단어는 뒤)라 약한 단어일수록 시험에 가까이 봄
    - 문제 순서(`sweepOrder`): 단어 20개씩 묶어 먼저 풀 문제의 묶음을 먼저, 그 묶음의 다른 문제는 다음 단어 묶음 뒤에(예문 먼저면 E1 E2 W1 E3 W2 …). 같은 단어의 두 문제가 붙어 나오면 앞 문제가 뒤 문제의 답을 보여 줘서이고, 중간에 그만둬도 두 모드를 고르게 한 셈. 무엇을 먼저 풀지는 '총정리 문제 > 먼저 풀 문제'에서 고름(처음엔 예문 빈칸)
    - 문제 방식은 학습 계획 > 문제의 **총정리 문제**에서 모드마다 따로(처음엔 단어 → 뜻 직접 입력, 예문 빈칸 4지선다. 목표일·시험일이 있을 때만 보임). 총정리 동안 위 문제 방식·'복습은 외운 단어만 4지선다' 대신 이걸 따름. 두 모드가 같이 쓰고 다시 나오기처럼 바꾼 시각(`sweepKindAt`)으로 기기끼리 맞춤
    - 결과는 그 문제의 모드 진도에 적음(단어 문제는 `voca.word.*`, 예문 문제는 `voca.*`, 동기화도 각 파일로. 다른 모드 파일이 Gist에 아직 없으면 새로 올림). 훑으며 푼 결과도 복습 일정에 반영(맞힌 단어가 며칠 뒤 또 나오지 않게). 그 모드로는 처음 보는 단어를 한 번에 맞히면 다른 모드에서 쌓은 단계를 이어받음(예문으로 다 아는 단어를 단어 문제로 처음 맞혔는데 내일 또 나오면 복습만 늘어서. 틀리면 처음부터)
    - 두 모드의 목표일이 다르면(코치 일정은 모드마다) 먼저 오는 쪽부터 총정리. 어느 모드에서 열든 같은 목록(문제마다 `w:id`·`e:id`, 오늘 고정한 목록은 모드마다 따로지만 오늘 본 문제는 두 모드 기록으로 셈)
    - 끝나면 '틀린 문제 다시 풀기'(단어 문제·예문 문제 그대로). 퀴즈 위에 '단어 → 뜻'·'예문 빈칸' 표시
    - 홈의 오늘 카드가 총정리 카드로 바뀜: '시험까지 n일'을 크게, 총정리 첫날부터 시험날까지 하루 한 칸(지난 날 ✓ · 오늘은 고리 · 쉬는 날은 빗금 · 맨 끝은 시험 깃발. 2주가 넘으면 앞의 지난 날은 '+n' 한 칸으로, 열흘 넘으면 요일 글자는 빼고), 오늘 남은 문제 수와 단어·예문 문제 수, 바퀴 막대(1바퀴는 두 모드로 다 본 단어 / 전체, 2바퀴는 끝낸 약한 단어 / 약한 단어. 옅은 부분은 오늘 몫까지 하면 닿을 곳. 2바퀴 날 칸은 점선). 시험이 가까울수록 카드 색이 달아오름: 8일 넘게 강조색 → 4~7일 보라 → 2~3일 주황→빨강 → 시험 전날 빨강 (`sweepHeat`)
  - 홈에 목표 D-n(목표일 뒤엔 총정리 카드 안에 시험까지 n일)
- 직접 입력엔 오답이 없음: 단어 원형(abound)도 예문 형태(abounds)도 정답. 원형이 예문 형태의 앞부분이면(outlaw → outlawed) 원형까지 쓰고 0.8초 멈추면 정답(확인 버튼과 예문 박스 테두리가 초록 게이지로 차오름. 힌트를 쓴 단어는 노랑). 설정에서 "바로 정답"으로 바꿀 수 있음. 정답이 될 때까지 계속 쓰고, 힌트를 쓴 단어는 잠시 후 한 번 더 나옴(외운 걸로 안 침)
- 직접 입력에서 틀린 답을 내거나, 정답에서 벗어난 채로 1.2초 멈추면 아까운 답일 때 말풍선으로 알려줌 (서버 없이 단어 데이터만으로)
  - 노랑: 철자가 1~3글자 다름(틀린 글자 빨강, 빠진 글자 _) · 빈칸을 덜 채움 · 같은 단어의 다른 형태 · 같은 뿌리의 다른 품사(파생어)
  - 초록: 유의어면 "뜻은 통하지만 문장에 더 딱 맞는 단어가 있어요(뉘앙스)", 뜻이 같은 단어장의 다른 단어면 "그것도 좋은데 다른 단어는? 첫 글자는 ○"
  - 반대말·상관없는 말·모르는 말엔 말풍선을 띄우지 않음
  - 설정의 AI(두 모드 공용, Groq 등 API 키)를 켜면: 철자 실수·빈칸 덜 채움은 그대로 바로, 그 밖의 틀린 답은 AI가 두 예문을 보고 1~2문장으로 풀이(초록 뉘앙스·쓰임 / 노랑 형태·품사 / 빨강 뜻이 다르거나 그 자리에 못 옴). 정답은 말하지 않고 새어 나오면 ○○로 가림. 같은 답은 한 번만 물어봄. 오프라인·한도 초과면 기본 말풍선
  - 말풍선은 2.5~4.5초 뒤 저절로 사라지고, 다시 쓰기 시작하면 바로 사라짐. 눌러도 아래 키보드·문장이 그대로 눌림
- DAY별 진도 막대: 학습한 단어는 연하게, 암기 완료(14일 간격까지 올라간 단어)는 진하게 채워짐. 숫자는 학습한 단어 수/전체
- DAY별 진도 박스: **누르면** 그 DAY 단어장(단어장의 DAY 고르기는 그대로, 이번에만) · **왼쪽으로 밀면** 그 DAY 유반의어 테스트(파랑→빨강 띠) · **오른쪽으로 밀면** 그 DAY 학습(연두→초록 띠). 다크 모드에선 띠·버튼 글자가 검정. 박스 폭의 30% 넘게 밀었다 놓거나 빠르게 휙 튕기면 실행, 덜 밀거나 위아래로 움직이면 그냥 스크롤(비스듬히 밀어도 가로가 더 크면 밀기). 컴퓨터에선 마우스로 끌어도 됨. 처음 몇 번은 박스가 살짝 흔들리며 안내하고(한 번 밀어 보면 그만), DAY 단어장 아래에도 같은 두 버튼이 있음
- 유반의어 테스트 (**학습 기록·복습 일정·다시 볼 단어에 영향 없음**, 이어하기에도 안 남음): 그 DAY에서 유의어·반의어가 있는 단어를 섞어서 4지선다
  - 예문 모드: 시험지처럼 예문 속 그 단어에 밑줄 → "밑줄 친 부분과 의미가 가장 비슷한(반대인) 것은?". 뜻이 여러 개인 단어는 예문 해석으로 몇 번째 뜻인지 찾아서 그 뜻의 유의어만 정답으로 냄. 어느 뜻인지 확실하지 않으면 예문 없이 단어만 보여 줌
  - 단어 모드: 유의어(반의어)를 보여 주고 그 단어 고르기
  - 위 태그 [유의어] 파랑 / [반의어] 빨강. 보기는 가까운 DAY의 단어장 단어(같은 품사 먼저)에서, 정답과 뜻이 비슷한 단어는 빼고. 반의어가 있으면 유의어 문제에 함정 보기로(반의어 문제엔 유의어를) 하나 넣음
  - 💡 힌트(예문 해석 / 단어 뜻), 🤷 모르겠어요, 컴퓨터는 1~4. 틀리면 3~5문제 뒤에 다시. 정답 시트에 '보기 풀이'(정답이 왜 정답인지, 다른 보기는 무슨 뜻인지)
  - 끝나면 틀린 단어만 다시 풀기, 다 맞혔으면 같은 DAY를 새 문제로 한 번 더
- DAY 박스를 오른쪽으로 밀면 '오늘' 카드가 그 DAY만 학습하는 카드로 바뀜. 퀴즈 화면 바탕 아래쪽 빛도 밀 때 띠 색을 따름(DAY 학습 = 연두→초록, 유반의어 테스트 = 파랑→빨강, 홈으로 가면 원래대로). 고른 DAY 박스와 시작 버튼이 같은 주황색으로 표시됨 (학습 범위·하루 새 단어 수·시험일·범위 연습 버튼과 홈의 학습 계획 요약은 회색으로, 문제 방식만 그대로, 기록은 정규 학습과 같이 쌓임. '정규 학습으로'를 누르면 돌아감)
- 다시 볼 단어(틀렸거나 힌트 쓴 단어) 복습: 여기서 힌트 없이 맞히면 그날은 목록에서 빠짐(복습 일정은 그대로라 다음 날 복습에 나옴)
- 범위 순서대로 연습: 몇 개 할지 고르고(전부도 가능), 다음엔 지난번에 한 데 다음부터 이어서
- 하던 학습이 있는데 다른 학습을 시작하면 물어봄(같은 오늘의 학습·복습이면 그냥 이어서). 단어장에서 시작한 형광펜 테스트를 그만두면 단어장으로 돌아감
- 단어장(전체/오답/미학습/암기 완료/형광펜/독해/졸업)
  - DAY 줄 맨 앞 '내 단어' 칩: 켜면 맨 위에 내 단어가 올린 날(마지막으로 적은 날)마다 새것부터. 날마다 '이 날 단어 풀기'(그날 올린 내 단어 + 그날 독해에서 막힌 단어책 단어), 묶음이 둘 넘으면 '전체 한 바퀴'(졸업한 단어도. 연습이라 맞힌 건 일정에 영향 없고 틀리면 다시 복습으로). 단어를 펼치면 '뜻 고치기'·'지우기'
  - 단어 옆 작은 표시: `독해`·`독해 ×n`(노트에 적은 횟수) · `OO의 파생어` · `지난 바퀴 n번 틀림`('단어책 새로 시작' 뒤) · 내 단어 묶음 밖에선 `내 단어`. 상태 글자에 `졸업`
  - '독해' 칩은 고른 DAY와 상관없이 내 단어 전부와 독해에서 막힌 단어책 단어, 검색도 내 단어(지문 문장까지)에서 찾음
  - 맨 위 DAY 줄에서 볼 DAY를 여러 개 고름(처음엔 학습 범위). 목록은 DAY별로 나뉘고, 형광펜 테스트도 고른 DAY에서만
  - DAY가 전부 켜져 있을 때 하나를 누르면 그 DAY만, 그 밖엔 켜고 끄기
  - 목록은 처음 몇 십 개만 바로 그리고 나머지는 이어서 그림(1000단어여도 바로 열림). 형광펜 친 단어가 없으면 아래 테스트 버튼은 숨김
  - 맨 위 검색 칸: 단어·뜻·유의어 등으로 전체 DAY에서 찾음. 뜻은 두 줄까지 보이고 단어를 누르면 예문과 함께 다 펼쳐짐
  - 예문·단어 모드 기록을 합쳐서 보여 줌: 틀린 횟수는 더하고, 단계는 높은 쪽, 어느 모드든 마지막에 틀렸으면 오답
  - 단어 옆에 유의어(초록) · 반의어(빨강)
  - 형광펜: 단어장이나 정답 화면에서 형광펜 아이콘을 누르면 단어에 형광펜이 칠해짐. 두 모드가 같이 쓰고 동기화됨(Gist의 `voca-marks.json`)
  - 단어장 아래 '형광펜 친 단어만 테스트'로 그 단어만 풀기
  - DAY 제목 옆 '기록 지우기'(또는 홈의 DAY 단독 학습 카드의 '이 DAY 기록 지우기')로 그 DAY의 학습 기록을 예문·단어 두 모드 모두 지움. 동기화된 다른 기기에서도 지워지고, 형광펜은 그대로
- 발음 듣기(브라우저 음성 합성, 미국식/영국식, 속도 조절). 기기 안 목소리를 먼저 씀(크롬·엣지의 인터넷 목소리는 한 박자 늦어서). 효과음은 화면을 처음 누를 때 소리 장치를 미리 깨워 둠
- 맨 위 카드의 '새 단어'·'복습' 숫자를 누르면 **오늘만** 남은 개수를 바꿈(예: 남은 3 → 14면 오늘 14개 더). 매일 새 단어 수는 학습 계획 화면의 '하루 새 단어' 버튼. 폰·패드는 앱 안 숫자 키패드(시스템 키보드 안 뜸), 컴퓨터는 숫자 치고 Enter. 복습은 '전부'도 고를 수 있음
- 카드 위 '학습 › 복습 › 더 하기'를 누르면 그 단계로 감 (학습·복습은 언제나 — 복습을 먼저 해도 됨, 더 하기는 둘 다 끝냈으면). 복습할 단어가 기다리면 학습 카드 아래에 개수를 알려 줌
- 진도는 폰 브라우저(localStorage)에 저장, 백업 파일로 내보내기/가져오기. 백업 파일 하나(`voca-backup-날짜.json`)에 예문·단어 두 모드의 진도·학습 설정과 형광펜, 내 단어가 모두 들어가고, 불러오면 파일에 든 모드를 모두 되돌림(예전 한 모드짜리 파일도 읽음. 동기화 중이면 다른 기기도 백업의 진도로). '진도 초기화'는 지금 보고 있는 모드만 지움(내 단어 기록이 있으면 같이 지울지 따로 물어봄, 내 단어 목록은 그대로)
- 단어책 새로 시작 (설정 > 연결 > 백업 · 앱 정보, 겨울방학처럼 단어책을 처음부터 다시 외울 때): 단어책 단어의 진도만 예문·단어 두 모드 모두 처음으로(졸업한 단어도). 내 단어 진도 · 독해에서 막힌 표시 · 형광펜은 그대로. 누르면 백업 파일을 먼저 받고, 지난 바퀴에 틀린 횟수를 단어마다 숫자 하나로 남김(단어장 `지난 바퀴 n번 틀림`). 기기끼리는 `bookResetAt`(이 시각 전 단어책 기록은 버림, `my|…`는 그대로)으로 맞춤 (`js/core.js`의 `mergeProgress`)
- 동기화할 때 지운 기록 표시(`{ del }`)는 90일이 지나면 버림 (`TOMB_KEEP`, 쌓이지 않게)
- 시험일은 예문·단어 모드가 같이 씀(한쪽에서 정하면 다른 쪽에도). 동기화할 때도 시험일은 다른 설정과 따로, 시험일을 더 최근에 바꾼 쪽으로 맞춤(한 모드에서 정한 시험일이 다른 모드의 하루 개수·복습 방식을 덮어쓰지 않음). 지난 날짜는 시험일로 못 정함
- 확인 창·숫자 키패드가 열린 채 뒤로 가기를 누르면 창만 닫힘. 설정에서 연 학습 계획 화면의 ←는 설정으로
- 폰·아이패드 진도 자동 동기화: 설정에서 `gist` 권한 GitHub 토큰을 기기마다 한 번 넣으면, 내 계정의 비밀 Gist(`voca-progress.json`)를 통해 단어별 최신 기록으로 합쳐짐. 학습 범위·하루 새 단어 수·시험일·복습 방식 설정·고른 코치 캐릭터도 더 최근에 바꾼 쪽으로 맞춰짐. 하던 학습(이어하기)도 맞춰져서 폰에서 풀다 그만둔 걸 컴퓨터에서 '이어서 학습하기'로 이어 풀 수 있음(더 최근에 풀거나 지운 기기 쪽으로. 지금 문제를 풀고 있는 기기는 건드리지 않음) (앱 열 때, 답한 뒤 몇 초 후, 학습 끝날 때, 앱에서 나갈 때). GitHub는 Gist 쓰기를 한 시간에 500번쯤까지만 받아서, 문제 풀 때 저절로 올리는 건 15초에 한 번까지만 모아서 올림(기기 둘이 동시에 풀어도 한 시간에 480번)(앱에서 나갈 때·학습 끝날 때는 바로). 그래도 GitHub가 막으면(403·429) '잠시 뒤 동기화'로 보이고, 그동안은 아무것도 안 보내다가(더 보내면 더 오래 막힘) GitHub가 알려 준 시간(없으면 1분·2분·4분 … 최대 1시간) 뒤에 알아서 다시 함. 진도는 기기에 그대로 있음. Gist가 지워졌으면(404) 오류로 안 보이고 그 자리에서 찾거나 새로 만듦
- 컴퓨터(마우스·키보드)에서 열면 화면 키보드 없이 실제 키보드로 입력(Enter 확인, Backspace 지우기, Shift만 눌렀다 떼면 힌트, 4지선다는 1~4, 정답 화면에서 Enter로 다음, 스페이스로 형광펜, Esc로 그만하기. 한글 자판 상태여도 누른 자리의 영문자로 입력됨). 단축키는 설정 > 단축키에서 바꿈(`js/keys.js`, 컴퓨터에서만 보임, 이 기기에만 저장): 보기 1~4·힌트·모르겠어요·계속하기·형광펜·발음 듣기·그만하기(처음엔 Space가 채점 다음 형광펜, 계속하기는 Enter. 형광펜은 칠할 때 바탕이 쓱 칠해지는 모션, 지울 때 빠지는 모션). 버튼을 누르고 쓸 키를 누르면 되고, 다른 동작이 쓰던 키면 서로 맞바꿈. Backspace·Delete는 '없음', Shift·Ctrl·Alt·⌘는 혼자 눌렀다 뗄 때만(왼쪽·오른쪽을 따로 붙일 수 있음. 처음 힌트의 Shift는 양쪽 다라서, 오른쪽 Shift를 다른 데 붙이면 힌트는 왼쪽 Shift로), Enter(채점·계속하기)와 Tab은 못 바꿈. 직접 입력 문제에선 글자 키가 입력으로 먼저 감. 창이 넓으면(1000px~) 퀴즈는 왼쪽 문제 / 오른쪽 정답 풀이로 두 칸 배치. 컴퓨터에선 문제를 화면 위아래 가운데에. 한 줄씩 놓은 선지가 창 아래로 넘치면 2×2로 줄여 한 화면에 보이게 함. 보기 번호(1~4)는 컴퓨터에서만 보임
- 홈 화면에 추가하면 앱처럼 실행, 오프라인에서도 마지막으로 받은 데이터로 동작 (앱 파일은 처음 열 때 미리 받아 둠)
- 이상한 점 알려 주기(버그 신고): 정답 시트의 형광펜 옆 작은 깃발을 누르면 그 문제를, 설정 맨 아래 '이상한 점 알려 주기'는 앱 전체를 신고. 이유를 골라(여러 개) 한 줄 적고 '보내기'를 누르면 로그인 없이 Google 설문지로 보내지고, 응답은 그 설문지에 연결한 Google 시트에 쌓임(Claude가 Google Sheets로 읽고 고침). 인터넷이 안 되면 이 기기에 쌓아 뒀다가(최대 30개) 다음에 앱을 열 때·인터넷이 돌아올 때 알아서 보냄. 설문지는 `js/report.js`의 `REPORT_FORM`(설문지의 '미리 채워진 링크'에서 id와 entry 번호)으로 정하고, 비어 있으면 예전처럼 GitHub 새 이슈 화면을 내용을 채워서 엶(GitHub 로그인 필요). 단어·DAY·모드·내 답·보기(고른 것·정답)·뜻·예문·해석(앱이 굵게 강조한 데는 \*\*로)·앱 버전·AI 회사·기기·최근 3일 오류(이 기기에서 잡힌 것 최대 8개 중 3개)가 같이 감. 학습 기록·API 키·토큰은 안 보냄. '내용만 복사하기'도 있음. 보낼 내용은 창의 '같이 보내는 내용'에서 미리 봄
- 설정 맨 아래에 앱 버전(예: 2026.11.02-0031)과 최신인지 표시. 앱을 열 때와 앱으로 돌아올 때 새 버전이 있으면 한 번 새로고침

## 내 단어 (독해 노트)

영어 문제를 풀다 모르는 단어를 노트에 적고(단어·뜻·지문 문장) → 노트 사진을 Claude 채팅에 주면 아래 형식으로 정리해 줌 → 앱에 올려서 공부. 두 모드가 같이 쓰고 기기끼리 맞춰짐(Gist `voca-mywords.json`). 로직은 `js/mywords.js`(테스트 `tests/mywords.test.mjs`).

- 올리기: 단어장 오른쪽 위 `+` 또는 설정 > 복습 > 내 단어 > '내 단어 올리기'. Claude가 준 코드 블록을 그대로 붙여넣거나(코드 블록 울타리·`#` 줄은 무시) CSV·TXT 파일을 고름. '부탁 문구 복사'를 Claude 채팅에 노트 사진과 같이 보내면 이 형식으로 줌(`CLAUDE_PROMPT`)
- 파일 형식 (첫 줄은 있어도 없어도 됨, 머리글이 없으면 이 순서로 봄, 칸을 탭으로 나눈 글도 읽음):

  ```
  # VOCA 내 단어 v1
  날짜,단어,빈칸형태,뜻,품사,예문,예문해석,예문2,예문2해석,출처
  2026-12-28,study,studied,연구하다,동,"Scientists have studied the effects of sleep on memory.",과학자들은 수면이 기억에 미치는 영향을 연구해 왔다.,She studies the history of art.,그녀는 미술사를 연구한다.,고2 11월 모의 31번
  ```
  `단어` = 원형, `빈칸형태` = 지문 속 실제 형태(원형과 같으면 비움), `뜻` = 그 지문에서 쓰인 뜻, `예문` = 노트에 적은 지문 문장(빈칸 퀴즈의 예문 1), `예문2` = Claude가 지은 쉬운 예문(예문 2), `출처`는 비워도 됨. 단어·뜻이 없거나 단어가 영어가 아닌 줄은 '못 읽은 줄'로 알려 줌
- 확인 화면: 줄마다 어디에 넣을지 보여 주고 바꿀 수 있음. 맞춰 보는 순서는 이미 있는 내 단어 → 단어책(원형·변화형: studied → study, gave up → give up. 같은 단어가 여러 DAY면 뜻이 겹치는 쪽) → 단어책 단어의 파생어 칸 → 새 단어
  - 단어책에 있으면 새로 만들지 않고 그 카드를 예문·단어 두 모드 모두 처음부터(0단계, 내일 복습, 졸업·4지선다 표시 지움) + `독해` 표시. 지문 문장은 그 카드의 예문 2 자리에 나옴(빈칸을 만들 수 있을 때만, `overlayHit`). 아직 안 배운 단어책 단어면 오늘의 학습에 내 단어처럼 먼저. '새 단어로'를 누르면 단어책과 따로 내 단어
  - 파생어(fatal ↔ fatality)는 다른 단어라 새 내 단어 + `fatal의 파생어` 표시. 'fatal로'를 누르면 단어책 단어로
  - 이미 있는 내 단어를 다른 문장에서 또 적으면 처음부터 다시(`독해 ×2`), 문장은 새것부터 3개까지(`MAX_SENT`)
  - 같은 문장을 이미 올렸으면 '이미 올림'으로 건너뜀(같은 파일을 두 번 올려도 카드가 또 처음으로 돌아가지 않게). 그래서 Claude에게는 그날 새로 적은 것만 받아서 올리면 되고, 쌓는 건 앱이 함
- 오늘의 학습: 단어책 하루 몫과 따로 내 단어 몫을 더함(홈 '오늘' 카드에 `내 단어 n`). 기다리는 순서는 독해에서 막힌 안 배운 단어책 단어 → 내 단어(올린 순)
  - 하루 새 내 단어(설정, 기본 20). 못 넣은 단어는 대기열에서 기다림
  - 한 번 배운 다음부터는 같은 간격 반복이라 오늘의 복습에 섞여 나옴(학습 범위와 상관없이). 졸업은 56일 간격
- 오늘의 복습에는 하루 상한이 없음: 복습일이 된 단어를 전부
- 내 단어 내보내기(CSV): 올릴 때와 같은 형식(독해에서 막힌 단어책 단어도). 다시 올려도 그대로이고, Claude에게 주고 시험지를 만들게 해도 됨
- 저장 크기: 두 모드 모두 졸업한 내 단어는 Claude 예문과 지난 지문 문장을 빼고 최근 지문 문장 하나만 남김(`slimMy`, 기기마다). 지운 내 단어 표시도 90일 지나면 버림
- 퀴즈·정답 화면의 DAY 자리엔 `내 단어`, 예문 위엔 `독해 · 출처`

## 예문 / 단어 모드

홈 화면 오른쪽 위 작은 전환 버튼으로 바꿔요. 두 모드는 **같은 화면·같은 흐름**(오늘의 학습, 간격 반복, 다시 볼 단어, 단어장, 설정·동기화·백업)이고 문제와 색만 달라요.

- **예문** (`./`): 두 예문의 빈칸에 들어갈 말 맞히기
- **단어** (`./?m=word`): 단어를 보고 뜻 맞히기
  - 4지선다: 뜻 보기 4개 (같은 범위에서, 정답과 뜻이 겹치지 않게). 틀리면 정답 시트의 '보기 풀이'에 보기마다 어느 단어의 뜻인지
  - 직접 입력: 폰 키보드로 한글 뜻을 씀. 채점은 설정의 느슨(뜻 하나만 통하면. AI를 켜면 비슷한 표현·동의어도 정답, 0점은 완전히 다른 단어의 뜻일 때만) / 보통(뜻 갈래마다 하나씩) / 엄격(뜻 낱말 전부). 세 단계 모두 오타·자모 깨짐·띄어쓰기·조사·어미·축약형·명사형·반말체·순서·번호·품사 표시·동의어 치환은 봐줌(AI 채점) (오타·어미·띄어쓰기는 무시). 뜻의 `[ ]`는 바로 앞말을 바꿔 쓸 수 있다는 표시라 그 말로 써도 정답(`식별[구별]하다` → 구별하다, `전문 지식[기술]` → 전문 기술). 오타는 자모 한두 개까지만 봐줌 — 한 글자가 통째로 다른 말(수입 ↔ 수출)은 다른 뜻이라 오답. 부분 정답은 '힌트 사용'처럼 단계 그대로 내일 다시
  - AI 재확인 (설정 > 직접 입력 채점 > '채점에 AI 사용하기' 스위치를 켜면 API 키 넣는 칸이 나옴. 키를 넣고 스위치가 켜져 있을 때만 동작, 스위치를 꺼도 키는 남음): 속도를 위해 먼저 위 규칙대로 바로 채점하고, 정답이 아닐 때(오답·부분 정답)만 인터넷이 되면 AI가 뜻을 이해해서 다시 확인함(단어장과 표현이 달라도 같은 뜻이면 정답, 느슨/보통/엄격 기준도 따름, 틀리거나 부분 정답이면 한 줄 설명). 규칙으로 정답인 건 AI를 부르지 않음. 같은 단어·같은 기준에 같은 답(띄어쓰기만 다른 것 포함)을 또 쓰면 지난번 AI 채점을 그대로 씀(이 기기에 최근 400개 기억, '왜 틀렸어?' 설명도 150개). 인터넷이 안 되거나 AI 호출이 실패하면(12초 넘게 걸림, 키 오류, 무료 한도 초과 등) 규칙 채점 결과 그대로. 키 앞부분으로 회사를 고름: `gsk_…` = Groq(무료, 가입만 하면 됨, 아주 빠름, 연결할 때 `openai/gpt-oss-120b` 등 쓸 수 있는 모델을 고름) / `sk-or-…` = OpenRouter(무료 모델, 하루 50번쯤) / `AIza…` = Google Gemini(무료 등급) / `sk-ant-…` = Anthropic Claude(유료: 채점·풀이·홈 말풍선·학습 끝 한마디는 싸고 빠른 Haiku 5.5, 코치와 이야기하기만 Sonnet 5.5. Sonnet이 막히면 Haiku로 넘어감). 무료는 하루 횟수 제한이 있음. 키는 그 기기의 브라우저에만 저장(동기화 안 함)되고, 서버 없이 브라우저에서 바로 API를 부름
  - 'AI에게 묻기' (AI 사용 스위치가 켜져 있고 키가 있고 인터넷이 될 때): 모든 문제의 정답 시트에 '뜻 · 예문' 옆 'AI' 탭이 생김(맞혔든 틀렸든, 예문·단어 모드·유반의어 모두). 탭 위에서부터 빠른 질문 버튼 → 입력칸 → 주고받은 이야기 순서이고, 그 문제의 단어를 두고 무엇이든 물어봄(뜻 차이, 어원, 외우는 요령, 예문 해석, 내 답도 맞는지 등). AI는 그 문제의 단어·뜻·예문·유의어 등·내 답·채점 결과를 알고 답해서 단어를 다시 쓸 필요 없음. 빠른 질문 버튼(틀렸으면 '왜 틀렸어?', 외우는 요령, 비슷한 단어와 차이, 어원, 다른 예문)은 이미 물은 것만 빠지고 계속 보임. 답이 오면 새 답이 보이게 내려 줌. 정답 시트는 탭마다 크기가 다름: 뜻은 내용만큼, 예문은 조금 더 높게, AI는 아직 안 물었으면 낮게 있다가 이야기가 생기면 대화창처럼 높아짐(빠른 질문은 한 줄로 옆으로 밀어 보고, 입력칸은 위에 고정, 이야기만 스크롤). 탭을 바꾸면 높이가 미끄러지듯 바뀜. 폰에서 AI 칸을 누르면 시트가 키보드 바로 위까지 차고 아래 버튼 줄은 잠깐 숨음. 단어 모드에서 틀렸을 때 '왜 틀렸어?'는 예전처럼 내 답이 실제로 어떤 뜻인지·정답과 뭐가 다른지·외우는 요령을 3~4문장으로 설명(같은 답이면 기억해 둔 설명). 그 단어 안에서는 이어서 물어볼 수 있고(앞선 8개까지 같이 넘김) 다음 문제로 넘어가면 사라짐. 보낼 때만 AI를 부르니 채점 속도·무료 한도와 상관없이 안 쓰면 안 씀. 코치용 키를 따로 넣었으면 그 키로(막히면 다른 모델로, Claude는 Sonnet), 없으면 채점용 키로. 못 받으면 까닭을 말하고 물은 말을 칸에 돌려놓음. 칸에 쓰는 동안은 퀴즈 단축키(Enter·Space·Shift 등)가 안 먹음
  - 💡 힌트: 유의어 (없으면 예문)
  - 모르겠어요: 4지선다·직접 입력 둘 다. 누르면 틀린 걸로 치고 정답을 보여 줌(설정의 '다시 나오기'대로 같은 학습 중 다시 + 내일 다시)
- 진도는 모드별로 따로 저장(`voca.*` / `voca.word.*`)되고, 동기화는 같은 Gist에 파일만 나눠서(`voca-progress.json` / `voca-word-progress.json`) 저장돼요. 토큰은 한 번만 넣으면 두 모드 모두 연결돼요.
- 예전 `meaning.html` 주소는 `./?m=word`로 넘어가요. 예전 단어 모드의 약한 단어는 처음 열 때 '다시 볼 단어'로 옮겨져요.

## 꾸미기 (설정 > 화면 · 문제 풀기)

- 화면: 밝기(폰 설정대로·늘 밝게·늘 어둡게) · 강조 색(인디고·숲·포도·코랄·먹색) · 글자 크기(예문·보기·정답 시트만 작게~더 크게) · 예문 글꼴(고딕·명조, 폰에 있는 글꼴) · 모서리(둥글게·조금·각지게) · 카드(평평하게·그림자·테두리) · 퀴즈 바탕(단색·피치·하늘·민트) · 홈에 보일 것(학습 계획·암기 진도, 다시 볼 단어·범위 연습. '오늘' 카드는 늘) · '꾸미기 처음대로'
- 문제 풀기: 정답 반응(차분하게·보통·신나게, 고르면 한 번 보여 줌) · 맞히면 효과음 · 틀리면 진동(진동이 되는 폰만, 아이폰 사파리는 안 보임) · 앱 키보드 키 높이(낮게·보통·높게) · 키 누를 때 소리
- 홈 DAY별 진도 제목 옆 버튼으로 보기 방식: 격자 · 줄 막대(한 줄에 DAY 하나) · 잔디(작은 칸 하나가 DAY, 배운 단어는 반, 암기 완료까지 하면 진하게). 셋 다 누르면 단어장, 밀면 학습·유반의어
- 저장은 `voca.look.v1`. 강조 색·카드·퀴즈 바탕은 예문·단어 모드마다 따로(예문 기본 인디고·평평하게·단색, 단어 기본 먹색·평평하게·단색. 저장 판 `v`가 2보다 옛날이면 그때의 기본값(예문 그림자·피치, 단어 테두리)을 새 기본으로 옮김 — 강조 색 저장 이름은 예전 그대로 `navy`), 나머지는 두 모드가 같이
- 동기화·백업에도 들어감: 동기화를 켠 기기끼리 더 최근에 꾸민 기기 것으로 맞춰지고(Gist의 `voca-marks.json` `look`, 바꾼 시각 `at`), 백업 파일에도 `look`으로 들어가 불러오면 그 꾸미기로 바뀜. 설정 > 화면 '꾸미기도 동기화·백업하기'를 끄면 그 기기는 꾸미기를 주고받지 않고 백업에도 안 넣음(이 스위치는 기기마다, 다른 기기는 그 기기 스위치대로). '꾸미기 처음대로'도 다른 기기로 퍼짐
- `js/look.js`가 `<head>`에서 첫 화면 전에 `<html data-theme data-accent …>`을 붙여서 깜빡이지 않음. 다크 색도 `@media` 대신 `data-theme="dark"`로. 상태 표시줄 색은 바탕색

## 화면 고칠 때 규칙 (style.css)

- 색·모서리·그림자는 `style.css` 맨 위 `:root`(라이트)와 그 아래 다크 블록에만 적고, 나머지는 `var(--…)`로 씀. 단어 모드 색은 `:root[data-mode="word"]`에서 덮어씀
  - 모서리: `--r-xs`(6) · `--r-sm`(8) · `--r-md`(12, 칸·작은 버튼) · `--r-lg`(14, 버튼·목록 줄·보기) · `--r-xl`(18, 카드) · `--r-2xl`(22, 창·시트) · `--r-pill`
  - 색 띠 위 글자는 `--on-ok` · `--on-bad` · `--on-warn` · `--on-hint` (다크에선 검정 쪽이라 밝은 띠 위에서도 읽힘)
- 알약 버튼(칩, 단어장 거르기, 코치 대화 칩)은 한 모양(`--chip-h` 34px), 테두리 없이 바탕색으로, 고른 것(`.on`)은 옅은 강조 바탕
- 설정 화면: 밑줄 탭, 묶음 제목은 카드 바깥 위 작은 회색, 카드 안은 '이름 ─ 값' 줄. 고르기 버튼(`.seg`)은 그대로 두고 모양만 바꿈(`js/app.js`의 `settingsRows`): 선택지가 둘셋이고 짧으면 줄 오른쪽 작은 버튼, 넷 이상이거나 길면 '값 ›' → 아래에서 올라오는 시트(`openPickSheet`, 시트에서 누르면 원래 버튼이 눌림). 다시 나오기 표·단축키는 한 줄로 줄이고 시트 안에서 고침
- 단어장: 거르기는 한 줄('DAY ▾' 누르면 시트에서 여러 DAY 고르기 + 전체·오답·미학습·암기 완료·형광펜 칩), DAY 하나 = 카드 하나에 단어는 줄(유의어는 펼쳤을 때만), 상태는 글자(새 단어 · 틀림 n · n단계 · 암기 완료)
- 문제 화면: 질문을 제목처럼 크게, DAY·문제 종류는 작은 글자, 힌트·모르겠어요는 보기 위 오른쪽 아이콘. 정답 시트: 발음 버튼은 단어 옆 아이콘, 아래엔 '계속하기' 하나
- 결과 화면: 숫자 셋(본 단어 · 바로 맞힘 · 틀렸거나 헷갈림)을 크게, 틀린 단어는 단어장처럼 카드 하나에 줄로
- 작은 버튼(`.btn.small`)은 36px, 카드 머리에 붙는 건 30px
- 아이콘은 이모지 대신 `js/app.js`의 `ICON`(선 굵기 1.9 SVG). 정적인 버튼은 `index.html`에 `data-icon="speak"`처럼 적으면 앱이 채움, 글자는 `<span class="lbl">`에 (바꿀 땐 `setLabel`)
- 꾸미기 값으로 바뀌는 건 토큰으로: 글자 크기 `calc(19px * var(--fz))`, 키 높이 `calc(46px * var(--key-k))`, 강조 색은 `--primary`·`--primary-soft`·`--on-primary`·`--blank`
- 화면별 CSS는 `body[data-screen="home"]`처럼 (`body:has(...)`는 DOM이 바뀔 때마다 문서 전체를 다시 따져서 느려서 안 씀)

## 앱 수정 후 배포

PR에서는 `js/app.js`의 `APP_VERSION`과 `version.txt`를 바꾸지 않아요. PR에 `머지 대기` 라벨을 붙여 두면 GitHub Actions(`.github/workflows/scheduled-merge.yml`)가 매일 07:30 · 12:30 · 17:30 · 22:30(한국 시간)에 오래된 것부터 main에 머지하고, 머지한 게 있으면 두 값을 같은 새 값으로 한 번만 올려요. 그러면 열려 있는 홈 화면 앱도 다음에 앱으로 돌아올 때 새 버전으로 새로고침돼요. (`node --test tests/core.test.mjs`가 두 값이 같은지 확인)

- 충돌로 머지 못 한 PR은 그대로 남고 Actions 실행이 실패로 표시돼요(알림 메일). 충돌을 풀면 다음 시간에 머지돼요.
- 급할 땐 Actions 탭 → '정해진 시간 머지' → Run workflow로 바로 돌릴 수 있어요.
- 저장소에 60일 동안 활동이 없으면 GitHub이 예약 실행을 멈출 수 있어요. 그땐 Actions 탭에서 다시 켜면 돼요.
