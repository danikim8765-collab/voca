# VOCA 빈칸 암기

폰 브라우저에서 쓰는 영단어 암기 웹앱입니다. 두 예문에 뚫린 빈칸에 **공통으로 들어갈 말**을 맞혀요.

## 데이터

저장소 루트에 있는 CSV 파일을 읽습니다(UTF-8 / UTF-8-BOM 모두 가능).

- `VOCA_26-37.csv`
- `VOCA_38-.csv` ← 새 DAY는 이 파일에 행만 추가해서 올리면 앱에 바로 반영돼요.

파일 이름을 바꾸거나 새 파일을 추가하려면 `js/app.js` 맨 위의 `DATA_FILES`를 고치면 됩니다.

컬럼은 머리글 이름으로 자동 인식해요. 순서는 상관없어요.

| 용도 | 인식하는 머리글 예시 |
|---|---|
| DAY | `DAY`, `Day`, `일차` (값은 `26`, `DAY 26` 모두 가능, 비어 있으면 위 행의 DAY를 이어받음) |
| 단어 | `단어`, `영단어`, `표현`, `word` |
| 뜻 | `뜻`, `의미`, `meaning` |
| 예문 / 예문2 | `예문`, `예문2` |
| 예문 해석 | `예문해석`, `예문2해석`, `해석`, `해석2` (해석의 뜻 부분은 굵게 강조) |
| 빈칸 정답 (선택) | `빈칸형태` — 없으면 `단어`로 예문에서 자동으로 찾음 |
| 형광 (선택) | `형광` 값이 `O`면 "형광" 표시 |
| (선택) | `품사`, `발음기호` — `유의어`·`반의어`·`파생어`·`표현숙어` 등 그 밖의 컬럼은 정답 화면에 그대로 표시 |

### 빈칸 만드는 방식

`빈칸형태`가 없으면 `단어` 컬럼으로 예문에서 찾아요. 변화형(convinced, studied, stopped, cutting), 불규칙 동사(flung, strode, took over), 떨어진 구동사(let his son down → [let] his son [down])도 찾아요.
`빈칸형태`를 쓸 땐 예문에 실제로 들어 있는 형태로 적고, 사이에 다른 말이 끼는 숙어는 `~`, `…`, `...`, `A`, `B`, `sb`, `sth`, `one's` 등으로 구분하면 됩니다.

- `convinced ~ of` → *She **[convinced]** the jury **[of]** his innocence.*
- `convince A of B`처럼 원형으로 적어도 예문의 `convinced`를 찾아서 빈칸으로 만들어요.
- `make up one's mind` → *She **[made up]** her **[mind]**.*

## 기능

- DAY 범위 선택(시작~끝, 최신 DAY, 최근 3 DAY, 전체, DAY별 진도에서 한 번 눌러 선택)
- 4지선다 / 직접 입력, 힌트(뜻 → 첫 글자)
- 틀린 단어는 4문제 뒤에 다시 나오고(맞힐 때까지), 다음 학습 때도 먼저 출제. 맞힌 단어는 1·3·7·14·30·60일 간격으로 복습
- 오답 복습, 단어장(전체/오답/미학습/암기 완료)
- 발음 듣기(브라우저 음성 합성, 미국식/영국식, 속도 조절)
- 진도는 폰 브라우저(localStorage)에 저장, 백업 파일로 내보내기/가져오기
- 홈 화면에 추가하면 앱처럼 실행, 오프라인에서도 마지막으로 받은 데이터로 동작
