# VOCA 빈칸 암기

폰 브라우저에서 쓰는 영단어 암기 웹앱입니다. 두 예문에 뚫린 빈칸에 **공통으로 들어갈 말**을 맞혀요.

## 데이터

저장소 루트에 있는 CSV 파일을 읽습니다(UTF-8 / UTF-8-BOM 모두 가능).

- `VOCA_26-37.csv`
- `VOCA_38-50.csv` ← 새 DAY는 이 파일에 행만 추가해서 같은 이름으로 올리면 앱에 바로 반영돼요.

파일 이름을 바꾸거나 새 파일을 추가하려면 `js/files.js`의 `DATA_FILES`를 고치면 됩니다. (예문·단어 모드가 같이 씀)

컬럼은 머리글 이름으로 자동 인식해요. 순서는 상관없어요.

| 용도 | 인식하는 머리글 예시 |
|---|---|
| DAY | `DAY`, `Day`, `일차` (값은 `26`, `DAY 26` 모두 가능, 비어 있으면 위 행의 DAY를 이어받음) |
| 단어 | `단어`, `영단어`, `표현`, `word` |
| 뜻 | `뜻`, `의미`, `meaning` |
| 예문 / 예문2 | `예문`, `예문2` |
| 예문 해석 | `예문해석`, `예문2해석`, `해석`, `해석2` (해석의 뜻 부분은 굵게 강조) |
| 빈칸 정답 (선택) | `빈칸형태` — 없으면 `단어`로 예문에서 자동으로 찾음 |
| 해석강조 (선택) | 해석에서 강조할 말. 뜻과 해석이 다른 말이라 자동으로 못 찾을 때 씀 (`highlights.json`에 단어별로 적어도 됨) |
| 형광 (선택) | 있어도 되지만 앱에는 표시하지 않음 |
| (선택) | `품사`, `발음기호` — `유의어`·`반의어`·`파생어`·`표현숙어` 등 그 밖의 컬럼은 정답 화면에 그대로 표시 |

### 빈칸 만드는 방식

숙어는 단어마다 칸이 하나씩 뚫려요(cutting off → [cutting] [off]). 직접 입력에서 한 칸을 다 채우면 다음 칸으로 넘어가요.

`빈칸형태`가 없으면 `단어` 컬럼으로 예문에서 찾아요. 변화형(convinced, studied, stopped, cutting), 불규칙 동사(flung, strode, took over), 떨어진 구동사(let his son down → [let] his son [down])도 찾아요.
`빈칸형태`를 쓸 땐 예문에 실제로 들어 있는 형태로 적고, 사이에 다른 말이 끼는 숙어는 `~`, `…`, `...`, `A`, `B`, `sb`, `sth`, `one's` 등으로 구분하면 됩니다.

- `convinced ~ of` → *She **[convinced]** the jury **[of]** his innocence.*
- `convince A of B`처럼 원형으로 적어도 예문의 `convinced`를 찾아서 빈칸으로 만들어요.
- `make up one's mind` → *She **[made up]** her **[mind]**.*

## 기능

- 홈은 오늘 할 일 위주: '오늘' 카드 → '학습 계획' 요약 카드(범위·문제 방식·하루 개수 한 줄 + 범위 진도) → 다시 볼 단어·범위 연습·단어장 → DAY별 진도. 요약 카드를 누르면 **학습 계획** 화면에서 학습 범위·문제 방식·하루 새 단어/복습 수·시험일을 바꿈. 설정 > 화면 > '홈 간단히 보기'를 끄면 예전처럼 홈에 모두 보임 (기기마다 저장, 예문·단어 모드 같이)
- DAY 범위 선택(시작~끝, 최신 DAY, 최근 3 DAY, 전체)
- 4지선다 / 직접 입력(앱 자체 영어 키보드 — 키 사이 틈이나 가장자리를 눌러도 가장 가까운 키가 눌림, 설정에서 폰 키보드로 변경 가능), 힌트(4지선다: 틀린 보기 두 개를 지움 · 직접 입력 1번: 맞게 쓴 데까지 + 2글자, 2번: 정답을 회색으로 보여주고 따라 쓰기 — 틀린 것으로 기록). 힌트를 쓴 채 그만둬도 그 문제는 힌트 쓴 걸로 남음. 4지선다 보기는 정답과 낱말 수가 같은 것부터 고름(숙어 문제에 한 단어 보기가 섞이지 않게)
- 간격 반복: 단어마다 단계(0~4)와 다음 복습일 저장
  - 힌트 없이 맞히면 단계 +1 → 1일 / 3일 / 7일 / 14일 뒤 복습
  - 힌트 쓰고 맞히면 단계 그대로 내일 다시, 틀리면(정답 보고 쓰기 포함) 0단계로 같은 학습 중 3~5문제 뒤 + 내일 다시
  - 오늘의 학습 = (시험 3일 전부터) 범위 단어 3등분 중 오늘 몫 → 새 단어(하루 개수만큼, 학습 범위에서 순서대로)
  - 홈의 '오늘' 카드 하나가 학습 → 복습 → 더 하기 순서로 바뀜
  - 오늘의 복습·추가 복습은 학습 범위 안의 단어에서만 고름
  - 오늘의 복습 (오늘의 학습을 끝내면 나옴) = 전에 배운 단어 20개: 복습일이 된 단어(오래 밀린 것부터) → 나머지는 약한 단어(단계 낮은, 많이 틀린, 오래 안 본 순). 오늘 배운 단어·오늘 이미 본 단어는 빼고, 시작할 때 그날 목록이 정해짐
  - 더 하기 (오늘의 복습까지 끝내면 나옴): 개수(5/10/20/40 버튼 또는 슬라이더로 5개 단위 5~100개)를 골라 추가 학습(범위의 다음 새 단어) / 추가 복습(오늘의 복습과 같은 방식으로 다음 단어들, 다 떨어지면 오늘 본·배운 단어도 약한 것부터 다시)
  - 학습이 끝나면 점수 대신 틀렸거나 헷갈린 단어 목록을 보여 주고, 그 단어만 다시 풀 수 있음
  - 시험일을 정하면 다음 복습일이 시험 전날을 넘지 않음
  - 복습일이 아닌 단어를 연습으로 맞힌 건 일정에 반영하지 않음 (틀리면 반영)
- 주기 복습 (설정 > 복습 방식의 '주기 복습' 스위치로 켬, 끄면 위의 기본 방식 그대로)
  - 목표일과 시험일을 둘 다 정해야 켜짐 (목표일 < 시험일)
  - 복습 주기 다섯 가지: 매우 짧게 1·1·2·3·5·8일 / 짧게 1·2·4·7·12일 / 보통(추천, 기본과 같음) 1·3·7·14일 / 길게 2·5·12·25일 / 매우 길게 3·8·18·40일. 마지막 단계면 암기 완료, 그 뒤로는 마지막 간격으로 계속. 새로 학습·복습하는 단어부터 적용. 기억 유지 그래프(간단한 망각 곡선 모형)로 비교
  - 목표일 전: 오늘의 복습 = 복습일이 된 단어(기본 제한 없음, 설정에서 20개까지로 줄일 수 있음). 복습일은 목표일 전날을 넘지 않음
  - 목표일부터 시험 전날: 새 단어 없이, 학습 범위 전부를 남은 날에 나눠 하루 몫씩 복습(빠진 날 몫은 다음 날 같이, 날이 남으면 두 바퀴째) + 복습일이 된 단어
  - 홈에 목표 D-n(목표일 뒤엔 시험 D-n)
- 직접 입력엔 오답이 없음: 단어 원형(abound)도 예문 형태(abounds)도 정답. 원형이 예문 형태의 앞부분이면(outlaw → outlawed) 원형까지 쓰고 0.8초 멈추면 정답(확인 버튼과 예문 박스 테두리가 초록 게이지로 차오름. 힌트를 쓴 단어는 노랑). 설정에서 "바로 정답"으로 바꿀 수 있음. 정답이 될 때까지 계속 쓰고, 힌트를 쓴 단어는 잠시 후 한 번 더 나옴(외운 걸로 안 침)
- 직접 입력에서 틀린 답을 내거나, 정답에서 벗어난 채로 1.2초 멈추면 아까운 답일 때 말풍선으로 알려줌 (서버 없이 단어 데이터만으로)
  - 노랑: 철자가 1~3글자 다름(틀린 글자 빨강, 빠진 글자 _) · 빈칸을 덜 채움 · 같은 단어의 다른 형태 · 같은 뿌리의 다른 품사(파생어)
  - 초록: 유의어면 "뜻은 통하지만 문장에 더 딱 맞는 단어가 있어요(뉘앙스)", 뜻이 같은 단어장의 다른 단어면 "그것도 좋은데 다른 단어는? 첫 글자는 ○"
  - 반대말·상관없는 말·모르는 말엔 말풍선을 띄우지 않음
  - 설정의 AI(두 모드 공용, Groq 등 API 키)를 켜면: 철자 실수·빈칸 덜 채움은 그대로 바로, 그 밖의 틀린 답은 AI가 두 예문을 보고 1~2문장으로 풀이(초록 뉘앙스·쓰임 / 노랑 형태·품사 / 빨강 뜻이 다르거나 그 자리에 못 옴). 정답은 말하지 않고 새어 나오면 ○○로 가림. 같은 답은 한 번만 물어봄. 오프라인·한도 초과면 기본 말풍선
  - 말풍선은 2.5~4.5초 뒤 저절로 사라지고, 다시 쓰기 시작하면 바로 사라짐. 눌러도 아래 키보드·문장이 그대로 눌림
- DAY별 진도 막대: 학습한 단어는 연하게, 암기 완료(14일 간격까지 올라간 단어)는 진하게 채워짐. 숫자는 학습한 단어 수/전체
- DAY별 진도 박스: **누르면** 그 DAY 단어장(단어장의 DAY 고르기는 그대로, 이번에만) · **왼쪽으로 밀면** 그 DAY 유반의어 테스트(파랑→빨강 띠) · **오른쪽으로 밀면** 그 DAY 학습(연두→초록 띠). 다크 모드에선 띠·버튼 글자가 검정. 박스 폭의 30% 넘게 밀었다 놓거나 빠르게 휙 튕기면 실행, 덜 밀거나 위아래로 움직이면 그냥 스크롤(비스듬히 밀어도 가로가 더 크면 밀기). 컴퓨터에선 마우스로 끌어도 됨. 처음 몇 번은 박스가 살짝 흔들리며 안내하고(한 번 밀어 보면 그만), DAY 단어장 아래에도 같은 두 버튼이 있음
- 유반의어 테스트 (**학습 기록·복습 일정·다시 볼 단어에 영향 없음**, 이어하기에도 안 남음): 그 DAY에서 유의어·반의어가 있는 단어를 섞어서 4지선다
  - 예문 모드: 시험지처럼 예문 속 그 단어에 밑줄 → "밑줄 친 부분과 의미가 가장 비슷한(반대인) 것은?". 뜻이 여러 개인 단어는 예문 해석으로 몇 번째 뜻인지 찾아서 그 뜻의 유의어만 정답으로 냄. 어느 뜻인지 확실하지 않으면 예문 없이 단어만 보여 줌
  - 단어 모드: 유의어(반의어)를 보여 주고 그 단어 고르기
  - 위 태그 [유의어] 파랑 / [반의어] 빨강. 보기는 가까운 DAY의 단어장 단어(같은 품사 먼저)에서, 정답과 뜻이 비슷한 단어는 빼고. 반의어가 있으면 유의어 문제에 함정 보기로(반의어 문제엔 유의어를) 하나 넣음
  - 💡 힌트(예문 해석 / 단어 뜻), 🤷 모르겠어요, 컴퓨터는 1~4. 틀리면 3~5문제 뒤에 다시. 정답 시트에 '보기 풀이'(정답이 왜 정답인지, 다른 보기는 무슨 뜻인지)
  - 끝나면 틀린 단어만 다시 풀기, 다 맞혔으면 같은 DAY를 새 문제로 한 번 더
- DAY 박스를 오른쪽으로 밀면 '오늘' 카드가 그 DAY만 학습하는 카드로 바뀜. 퀴즈 화면 바탕 아래쪽 빛도 밀 때 띠 색을 따름(DAY 학습 = 연두→초록, 유반의어 테스트 = 파랑→빨강, 홈으로 가면 원래대로). 고른 DAY 박스와 시작 버튼이 같은 주황색으로 표시됨 (학습 범위·하루 새 단어 수·시험일·범위 연습 버튼과 홈의 학습 계획 요약은 회색으로, 문제 방식만 그대로, 기록은 정규 학습과 같이 쌓임. '정규 학습으로'를 누르면 돌아감)
- 다시 볼 단어(틀렸거나 힌트 쓴 단어) 복습: 여기서 힌트 없이 맞히면 그날은 목록에서 빠짐(복습 일정은 그대로라 다음 날 복습에 나옴)
- 범위 순서대로 연습: 몇 개 할지 고르고(전부도 가능), 다음엔 지난번에 한 데 다음부터 이어서
- 하던 학습이 있는데 다른 학습을 시작하면 물어봄(같은 오늘의 학습·복습이면 그냥 이어서). 단어장에서 시작한 형광펜 테스트를 그만두면 단어장으로 돌아감
- 단어장(전체/오답/미학습/암기 완료/형광펜)
  - 맨 위 DAY 줄에서 볼 DAY를 여러 개 고름(처음엔 학습 범위). 목록은 DAY별로 나뉘고, 형광펜 테스트도 고른 DAY에서만
  - DAY가 전부 켜져 있을 때 하나를 누르면 그 DAY만, 그 밖엔 켜고 끄기
  - 맨 위 검색 칸: 단어·뜻·유의어 등으로 전체 DAY에서 찾음. 뜻은 두 줄까지 보이고 단어를 누르면 예문과 함께 다 펼쳐짐
  - 예문·단어 모드 기록을 합쳐서 보여 줌: 틀린 횟수는 더하고, 단계는 높은 쪽, 어느 모드든 마지막에 틀렸으면 오답
  - 단어 옆에 유의어(초록) · 반의어(빨강)
  - 형광펜: 단어장이나 정답 화면에서 형광펜 아이콘을 누르면 단어에 형광펜이 칠해짐. 두 모드가 같이 쓰고 동기화됨(Gist의 `voca-marks.json`)
  - 단어장 아래 '형광펜 친 단어만 테스트'로 그 단어만 풀기
  - DAY 제목 옆 '기록 지우기'(또는 홈의 DAY 단독 학습 카드의 '이 DAY 기록 지우기')로 그 DAY의 학습 기록을 예문·단어 두 모드 모두 지움. 동기화된 다른 기기에서도 지워지고, 형광펜은 그대로
- 발음 듣기(브라우저 음성 합성, 미국식/영국식, 속도 조절)
- 맨 위 카드의 '새 단어'·'복습' 숫자를 누르면 **오늘만** 남은 개수를 바꿈(예: 남은 3 → 14면 오늘 14개 더). 매일 개수는 학습 계획 화면의 '하루 새 단어 수'·'하루 복습 수' 버튼. 폰·패드는 앱 안 숫자 키패드(시스템 키보드 안 뜸), 컴퓨터는 숫자 치고 Enter. 주기 복습에선 '전부'도 고를 수 있음
- 카드 위 '학습 › 복습 › 더 하기'를 누르면 그 단계로 감 (학습·복습은 언제나 — 복습을 먼저 해도 됨, 더 하기는 둘 다 끝냈으면). 복습할 단어가 기다리면 학습 카드 아래에 개수를 알려 줌
- 진도는 폰 브라우저(localStorage)에 저장, 백업 파일로 내보내기/가져오기
- 시험일은 예문·단어 모드가 같이 씀(한쪽에서 정하면 다른 쪽에도). 지난 날짜는 시험일로 못 정함
- 확인 창·숫자 키패드가 열린 채 뒤로 가기를 누르면 창만 닫힘. 설정에서 연 학습 계획 화면의 ←는 설정으로
- 폰·아이패드 진도 자동 동기화: 설정에서 `gist` 권한 GitHub 토큰을 기기마다 한 번 넣으면, 내 계정의 비밀 Gist(`voca-progress.json`)를 통해 단어별 최신 기록으로 합쳐짐. 학습 범위·하루 새 단어 수·시험일·복습 방식 설정도 더 최근에 바꾼 쪽으로 맞춰짐 (앱 열 때, 답한 뒤 몇 초 후, 학습 끝날 때, 앱에서 나갈 때)
- 컴퓨터(마우스·키보드)에서 열면 화면 키보드 없이 실제 키보드로 입력(Enter 확인, Backspace 지우기, Shift만 눌렀다 떼면 힌트, 4지선다는 1~4, 정답 화면에서 Enter·스페이스로 다음, Esc로 그만하기. 한글 자판 상태여도 누른 자리의 영문자로 입력됨). 창이 넓으면(1000px~) 홈은 왼쪽 오늘·범위·설정 / 오른쪽 DAY별 진도, 퀴즈는 왼쪽 문제 / 오른쪽 정답 풀이로 두 칸 배치. 컴퓨터에선 문제를 화면 위아래 가운데에
- 홈 화면에 추가하면 앱처럼 실행, 오프라인에서도 마지막으로 받은 데이터로 동작 (앱 파일은 처음 열 때 미리 받아 둠)
- 설정 맨 아래에 앱 버전(예: 2026.11.02-0031)과 최신인지 표시. 앱을 열 때와 앱으로 돌아올 때 새 버전이 있으면 한 번 새로고침

## 예문 / 단어 모드

홈 화면 오른쪽 위 전환 버튼으로 바꿔요. 두 모드는 **같은 화면·같은 흐름**(오늘의 학습, 간격 반복, 다시 볼 단어, 단어장, 설정·동기화·백업)이고 문제와 색만 달라요.

- **예문** (`./`): 두 예문의 빈칸에 들어갈 말 맞히기
- **단어** (`./?m=word`): 단어를 보고 뜻 맞히기
  - 4지선다: 뜻 보기 4개 (같은 범위에서, 정답과 뜻이 겹치지 않게)
  - 직접 입력: 폰 키보드로 한글 뜻을 씀. 채점은 설정의 느슨(뜻 하나만 통하면. AI를 켜면 비슷한 표현·동의어도 정답, 0점은 완전히 다른 단어의 뜻일 때만) / 보통(뜻 갈래마다 하나씩) / 엄격(뜻 낱말 전부). 세 단계 모두 오타·자모 깨짐·띄어쓰기·조사·어미·축약형·명사형·반말체·순서·번호·품사 표시·동의어 치환은 봐줌(AI 채점) (오타·어미·띄어쓰기는 무시). 부분 정답은 '힌트 사용'처럼 단계 그대로 내일 다시
  - AI 재확인 (설정 > 직접 입력 채점 > '채점에 AI 사용하기' 스위치를 켜면 API 키 넣는 칸이 나옴. 키를 넣고 스위치가 켜져 있을 때만 동작, 스위치를 꺼도 키는 남음): 속도를 위해 먼저 위 규칙대로 바로 채점하고, 정답이 아닐 때(오답·부분 정답)만 인터넷이 되면 AI가 뜻을 이해해서 다시 확인함(단어장과 표현이 달라도 같은 뜻이면 정답, 느슨/보통/엄격 기준도 따름, 틀리거나 부분 정답이면 한 줄 설명). 규칙으로 정답인 건 AI를 부르지 않음. 인터넷이 안 되거나 AI 호출이 실패하면(12초 넘게 걸림, 키 오류, 무료 한도 초과 등) 규칙 채점 결과 그대로. 키 앞부분으로 회사를 고름: `gsk_…` = Groq(무료, 가입만 하면 됨, 아주 빠름, 연결할 때 `openai/gpt-oss-120b` 등 쓸 수 있는 모델을 고름) / `sk-or-…` = OpenRouter(무료 모델, 하루 50번쯤) / `AIza…` = Google Gemini(무료 등급) / `sk-ant-…` = Anthropic Claude Sonnet 5.5(유료). 무료는 하루 횟수 제한이 있음. 키는 그 기기의 브라우저에만 저장(동기화 안 함)되고, 서버 없이 브라우저에서 바로 API를 부름
  - '왜 틀렸어?' (AI 사용 스위치가 켜져 있고 키가 있고 인터넷이 될 때): 오답·부분 정답이면 정답 시트의 뜻 탭에 버튼이 나옴. 누르면 AI가 내 답이 실제로 어떤 뜻인지(보기를 골랐으면 어떤 다른 단어의 뜻인지), 정답과 뭐가 다른지, 외우는 요령을 3~4문장으로 설명. 누를 때만 부르니 채점 속도와는 상관없음
  - 💡 힌트: 유의어 (없으면 예문)
  - 🤷 모르겠어요: 4지선다·직접 입력 둘 다. 누르면 틀린 걸로 치고 정답을 보여 줌(같은 학습 중 3~5문제 뒤 + 내일 다시)
- 진도는 모드별로 따로 저장(`voca.*` / `voca.word.*`)되고, 동기화는 같은 Gist에 파일만 나눠서(`voca-progress.json` / `voca-word-progress.json`) 저장돼요. 토큰은 한 번만 넣으면 두 모드 모두 연결돼요.
- 예전 `meaning.html` 주소는 `./?m=word`로 넘어가요. 예전 단어 모드의 약한 단어는 처음 열 때 '다시 볼 단어'로 옮겨져요.

## 앱 수정 후 배포

PR에서는 `js/app.js`의 `APP_VERSION`과 `version.txt`를 바꾸지 않아요. PR에 `머지 대기` 라벨을 붙여 두면 GitHub Actions(`.github/workflows/scheduled-merge.yml`)가 매일 12:00 · 18:30(한국 시간)에 오래된 것부터 main에 머지하고, 머지한 게 있으면 두 값을 같은 새 값으로 한 번만 올려요. 그러면 열려 있는 홈 화면 앱도 다음에 앱으로 돌아올 때 새 버전으로 새로고침돼요. (`node --test tests/core.test.mjs`가 두 값이 같은지 확인)

- 충돌로 머지 못 한 PR은 그대로 남고 Actions 실행이 실패로 표시돼요(알림 메일). 충돌을 풀면 다음 시간에 머지돼요.
- 급할 땐 Actions 탭 → '정해진 시간 머지' → Run workflow로 바로 돌릴 수 있어요.
- 저장소에 60일 동안 활동이 없으면 GitHub이 예약 실행을 멈출 수 있어요. 그땐 Actions 탭에서 다시 켜면 돼요.
